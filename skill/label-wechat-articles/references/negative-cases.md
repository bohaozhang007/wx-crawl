# 典型排除与对照案例

使用本文件校准容易误收的内容。具体文章仍必须完整阅读，并按
`decision-tree.md` 逐节点判断。

| 内容 | 决策 | 典型节点 | 关键区别 |
|---|---|---|---|
| “某项目拟入选名单公示” | DROP | `O1-D1` | 已是结果，不再开放申报 |
| “某研究中心召开大模型项目研讨会” | DROP | `O1-D2` | 报道会议，不是项目征集 |
| “具身智能大会开放参会报名” | DROP | `O1-D4` | 报名对象是活动，不是科研任务 |
| “人工智能产业政策解读” | DROP | `O1-D3` | 只有政策信息，没有申报动作 |
| “机器人企业完成新一轮融资” | DROP | `O1-D6` | 企业新闻，不是开放科研机会 |
| “优秀大模型应用案例征集” | DROP | `R1-D4` | 征集既有案例，不要求完成研发任务 |
| “机器人创新创业大赛报名” | DROP | `R1-D2` | 普通赛事；若另有技术榜单和验收指标才继续判断 |
| “征求卫星产业规划意见” | DROP | `R1-D3` | 征集的是政策文字意见，不是科研项目 |
| “科研课题申报，背景提到大模型，任务研究财税制度” | DROP | `D1-D1` | 大模型不在课题任务中 |
| “智能模型优化课题” | DROP | `D1-D2` | “模型”不能证明是大模型 |
| “材料研究项目使用机器人搬运样品” | DROP | `D1-D3` | 机器人只是工具，不是研究对象 |
| “科研项目申报，任务是生物育种” | DROP | `D1-D4` | 是科研项目，但不属于目标方向 |
| “详见附件”，附件含全部榜单且无法读取 | REVIEW | `T1-R1` | 已知是科研申报，方向证据缺失 |
| “大模型关键技术揭榜，含任务指标、期限和申报入口” | KEEP | `K1` | 可申报结构和任务方向均有直接证据 |

## 对抗性成对检查

- 申报通知 vs. 入选名单：关键词可高度相似，当前动作不同。
- 科研任务征集 vs. 会议议程：技术主题可相同，提交对象不同。
- 任务研究大模型 vs. 背景提到大模型：词相同，证据区域不同。
- 机器人技术榜单 vs. 机器人应用案例征集：前者要求研发，后者汇集既有成果。
- 卫星项目 vs. 空天项目：默认不继承领域，只有任务文本分别支持时才双标签。
